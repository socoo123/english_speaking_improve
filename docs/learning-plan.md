# 学习目标与推进规则

## 目标

学习者自评约 B1，待口语诊断。周期约 26 周，每周 10 小时，总计约 260 小时。目标是在熟悉技术工作场景中向 B2 沟通能力迈进，不承诺正式 CEFR 等级或所有场景都流利。

按训练时间分配：80% 工作会议与技术面试，20% 生活和旅游。工作包括需求澄清、架构讨论、方案权衡、进度同步、故障沟通、项目经历与面试。可每五次场景训练安排一次生活任务。

当前以通用美式英语（General American）为参考，重视音素、词重音、句重音、意群、连读与语调，为未来向孩子示范建立稳定基础。口音不等于能力不足，不要求消除个人身份特征。印度英语等口音训练留到半年后。

## 周课程主页

网站只保留一个学习主页，用标签页组织当周课文、词汇句型、练习、外教陪练与反馈。data/lessons.json 中每课的 week 是计划周次（1—26），不是日历上的自动倒计时；未通过时可以跨实际周继续补练。

进度条只统计有 reviewedAt 且 status 为 passed 的正式记录对应的周次；同一周有多课时全部通过后计一次。收到外教报告、核对证据并获学习者确认后，更新 data/progress.json、保留历史，再添加下一周课程及专属外教要求。暂存报告和网页校验都不直接写入正式记录。

## 课程节奏

初期优先约 2—5 分钟自然清晰的美音视频，中期约 5—10 分钟，后期长视频按目标拆分并标明时间戳。以上是选材目标，不是已核实素材信息。每章有核心必练和可选拓展；背诵之后必须脱稿复述并迁移到新场景。

每周：精听 2 小时；跟读/背诵/复述 2.5 小时；表达/语法/自测 1.5 小时；GPT 对话与发音纠正 3 小时；测评/复习 1 小时。每章可跨周，不为进度跳过考核。视频未就绪时可使用标明原创的练习，但不声称完成视频学习。

## 动态推进

1. 首先进行 10—15 分钟语音诊断：自我介绍、项目介绍、需求追问、简单方案比较与生活交流。
2. 学习、练习、陪练后，学习者明确表示准备好正式测试。
3. 外教生成至少两个未练过的场景，独立测试，不提前给答案或目标句型。
4. 输出结构化反馈，包含具体证据、发音纠正和复测、评分与补练建议。
5. 学习者把报告带回项目。网页只校验格式和条件，显示待复核，不自动晋级。
6. 维护者核对证据及学习者意见，更新 data/progress.json 的脱敏记录；信息不足先补测。
7. 正式通过且本人确认后，根据薄弱项和兴趣推荐下一课。后续课程持续复习旧内容。

## 评分

五项各 0—5 分：任务完成、互动理解、语言运用（表达/语法）、口语流畅度、发音。五项之和乘 4 为百分制总分；任何缺项则总分为 null，不能当作 0 分或完整成绩。

| 分数 | 含义 |
| --- | --- |
| 0 | 有实际测试证据，但未能完成该项任务；缺证据用 null。 |
| 1 | 严重依赖提示，表现不稳定。 |
| 2 | 完成部分任务，频繁需要帮助。 |
| 3 | 基本独立完成，仍有反复出现的问题。 |
| 4 | 稳定独立完成，少量问题不妨碍目标。 |
| 5 | 新增限制和追问下依然稳定、清楚、自然。 |

过关建议必须同时满足：本人准备好；确实分析了音频；至少两个新场景；无辅导提示；所有项 ≥3，任务完成 ≥4，发音 ≥4，总分 ≥80。这是项目内教学标准，不是 CEFR 认证。

发音 4 分要求本章重点音素和词重音在独立表达中总体稳定，意群与句重音帮助理解；发现的问题经过纠正并在新句中复测。5 分要求在即兴对话中保持。不使用“无口音”标准。纠正后仍不稳定时，继续补练，不能只因交流可理解便忽略。

## 正式记录

初始为 not_assessed、分数 null。后续按实际情况记录 needs_practice 或 passed，注明测评日期、报告来源、复核日期、分项分数和脱敏依据，保留既往测评摘要。勾选完成、背诵完成和选择题成绩都不是口语成绩。原始报告默认只在本地保存，不公开录音、个人信息或工作机密。
