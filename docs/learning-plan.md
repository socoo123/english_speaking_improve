# 学习目标与推进规则

学习者自评约 B1，每周约 10 小时，26 周约 260 小时。目标是在熟悉技术工作场景中向 B2 沟通能力迈进；学时不自动对应语言等级。80% 时间用于工作会议、需求澄清、架构讨论、技术面试，20% 用于生活和旅游。当前以通用美式英语为目标，半年后再扩展印度英语等口音。

## 周次与页面

第 0 周为 2026-11-02（周一）至 11-08（周日）。按周一划分，26 周编号为 0—25，计划最后一周为 2027-04-26 至 05-02。工作忙可以跨周补学，日期不会自动推进学习进度。课程 ID 与周次独立，不因改周次而丢失记录。

网站只有一个课程主页，用标签页组织视频与自评、词汇句型、可选练习、外教陪练、反馈。只准备当前课程，下一课根据反馈生成，不预先锁死半年内容。

## 视频、对话与调整

1. 直接从视频开始，不另设入学考试。前期目标约 5 分钟，优先 4—6 分钟的美音视频，优先 YouTube 与有可复用课文的官方来源。
2. 看一遍后选择简单／适合／困难，记录卡点、字幕和倍速。内置英文字幕的课程不能记成无字幕观看。
3. GPT 先询问观看感受，再让学习者复述内容、自然回答追问，并把表达用到工作与生活新场景。先观察独立回答，卡住后可以提供提示，记录提示前后的区别。
4. 根据真实对话和自评，建议降低难度、保持、略微提高、重练或补充观察。一次只调一个主要因素，如语速、词汇密度、句子复杂度、话题或输出支持。前期先保持约 5 分钟，稳定后再增加时长，长视频可分期。
5. 学习者带回 JSON 反馈，维护者核对证据和本人意见，更新脱敏正式记录与调整建议。困难时可以直接换简单视频，不必先通过旧课。没有固定的 80 分、发音 4 分或场景数门槛。
6. 本人确认本周学得差不多、且反馈复核支持完成时，记录 completed 和 reviewedAt，再更新进度。需要继续练的记录 needs_practice。下一课继续复习旧表达和未稳定发音点。

## 每周约 10 小时

精听 2 小时；跟读、背诵与复述 2.5 小时；词汇、语法与可选练习 1.5 小时；外教对话与发音纠正 3 小时；反馈与复习 1 小时。背诵服务于迁移，不要求先背完才能交流。

## 观察与评分

task、interaction、language、fluency、pronunciation 五项可分别记录 0—5 分；没有证据填 null。0 是实际尝试但未完成；1 严重依赖提示；2 部分完成且常需帮助；3 基本独立；4 稳定独立；5 在新限制和追问下仍稳定自然。仅五项完整时汇总为总分（总和乘 4），分数用于描述变化，不控制选课。文字会话不能评口语流畅度或发音。

认真纠正发音，每轮聚焦真实听到的 1—3 个问题，在新句中复测；未稳定的点带入后续课程。不能把能理解等同于发音已掌握，也不以“无口音”为标准。

## 正式记录

data/progress.json 初始 not_assessed、分数 null。只有 completed（或兼容旧 passed）且有 reviewedAt 的正式记录计入进度；同周多课须全部完成，只计一次。网页自评、暂存报告和做题成绩均不更新正式进度。新记录保留历史、来源与脱敏摘要；只有外教报告时说明依据是报告，不能声称独立核听音频。不要公开录音、原始个人报告或公司资料。
