# 视频与文本素材规则

## 选择顺序

1. 优先 YouTube 上清晰自然的通用美式英语，B 站为补充，仍核实原作者。
2. 优先官网提供字幕/课文下载，且明确允许相应教学复用或转载的课程。能下载不代表能公开转载。
3. 初期约 2—5 分钟，难度适合约 B1，重点是可迁移的沟通表达。
4. 可调查 VOA Learning English 等美音课程，但逐条核实页面、音视频和第三方内容的许可，不笼统认定整个网站全部内容可自由转载。

## 每个来源的核实项目

- 原始页面、作者/频道、准确标题及 YouTube video ID。
- 是否可播放及允许嵌入、核实日期；不保证未来一直可用。
- 实际时长、选学时间戳、美音及难度的人工检查记录。
- 字幕/逐字稿下载地址、是否自动字幕、是否匹配视频。
- 许可地址、适用范围、允许行为、署名要求、限制与核实日期。
- 本站使用方式：嵌入、链接、短引用、授权转载或原创配套材料。

仅在信息核实后将 source.status 改为 verified，并填写 youtubeId。保留许可说明和原站链接。转载受限时使用概述、必要短引用和原创课文，不完整复制无许可字幕。不得绕过付费墙、下载限制或环境网络策略。
