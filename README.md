# Speak at Work · 半年英语口语计划

无需构建的静态学习网站：从约 B1 出发，每周约 10 小时，用半年（约 260 小时）提升工作会议与技术面试中的英语表达。

- **80% 工作、20% 生活**：需求讨论、架构讨论、方案权衡、进度同步、故障沟通、技术面试，辅以旅游和日常交流。
- **目前以通用美式英语为目标**：认真纠正发音，培养稳定示范和自我纠正能力；半年后再增加印度英语等口音训练。
- **按掌握程度推进**：本人确认准备好 → GPT 独立测试 → 带回反馈 → 复核并更新正式成绩 → 推荐下一课。
- 目标是向熟悉工作场景中的 B2 沟通能力迈进，不保证学时自动对应语言等级。

## 当前内容

网站包含学习目标、基线诊断指令、第一课原创练习、词汇与语法、互动选择题与填空题、每课外教要求、反馈模板、本地反馈校验及正式学习记录。

**第一课是原创练习示范，视频尚待选定及核实许可。** 当前环境访问 YouTube、VOA 被网络策略拦截，未获取、转载或声称验证任何视频字幕。播放器仅在来源核实后启用。

## 本地运行与验证

要求 Python 3。网站无第三方运行依赖，不需要 API 密钥。

```bash
cd /workspace/english_speaking_improve
python3 -m http.server 8000 --bind 127.0.0.1
```

通过 HTTP 访问，勿直接双击 HTML：页面使用 fetch 读取课程数据。测试需要 Node.js 18 或更新版本：

```bash
node --test tests/*.test.mjs
```

## GitHub Pages 发布

在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支选择 main，目录选择 / (root)。所有资源采用相对路径，适用于仓库子路径。不自动开启部署；推送代码不代表网站已发布。

也可将静态文件交给支持静态网站的平台。ChatGPT 内发布能力以具体产品支持为准。

## 与 GPT 外教协作

1. 首次复制网站里的诊断指令，在支持原始音频分析的 GPT 会话中完成初测。
2. 学习本章内容后，复制本课完整外教指令，先陪练再进行独立测试。
3. 复制外教 JSON 报告到网页，校验并暂存本浏览器，或下载备份。
4. 将报告发回维护项目的对话。核对证据后更新 data/progress.json，再决定补练或下一课。

网页不连接 GPT，不分析音频，也不自动判定 CEFR。浏览器反馈草稿与仓库正式记录分开；换设备可粘贴备份 JSON 恢复。文字测验不能代表口语能力。

不要向公开仓库提交公司机密、真实同事姓名、个人录音或未经脱敏的原始报告。正式记录只保留脱敏摘要。
