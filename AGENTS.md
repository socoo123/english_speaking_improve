# Project instructions

- This cloud task already has an isolated checkout. Use it; do not create a Git worktree unless explicitly requested.
- Read docs/learning-plan.md, docs/tutor-rules.md and docs/source-policy.md before creating lessons or updating results.
- Learner: approximately B1, 26 weeks, 10 hours/week, 80% work/technical interviews and 20% daily life/travel. Target General American pronunciation now; other accents are a later extension.
- Do not pre-generate or unlock a full sequence. Recommend the next lesson only after learner confirmation and a reviewed passing assessment. Every lesson needs its own tutor instructions and feedback template.
- Never invent scores, heard pronunciation errors, video IDs, subtitles, timestamps, duration or licenses. Text-only sessions cannot assess pronunciation or oral fluency.
- Keep browser feedback drafts separate from official data/progress.json. Review evidence and learner confirmation before updating official results. If only a tutor report was supplied, do not claim independent audio verification.
- Public results contain anonymized summaries only. Do not commit raw recordings, personal reports, employer information or secrets.
- Downloadable captions do not establish republication rights. Record source URLs, license scope, attribution, verification date and limitations. Label original exercises as original.
- Preserve relative URLs and GitHub Pages subpath support. Keep this static site dependency-free unless functionality requires otherwise.
- Validate using node --test tests/*.test.mjs, an HTTP smoke check and browser checks for affected interactions.
