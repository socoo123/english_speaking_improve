# 字体来源

字体文件在本站托管，不请求外部字体服务。Noto Sans SC 按 CSS unicode-range 加载所需字符分片。

- Inter Variable 5.3.0：Fontsource npm 包 `@fontsource-variable/inter`，使用 latin / wght / normal 文件。原作者与 SIL Open Font License 见 Inter-LICENSE.txt。
- Noto Sans SC Variable 5.3.1：Fontsource npm 包 `@fontsource-variable/noto-sans-sc`，保留 index.css 引用的 wght / normal 文件与 unicode-range。Noto Sans SC 与思源黑体同源；许可证见 NotoSansSC-LICENSE.txt。
- 来源：https://registry.npmjs.org/@fontsource-variable/inter/-/inter-5.3.0.tgz
- 来源：https://registry.npmjs.org/@fontsource-variable/noto-sans-sc/-/noto-sans-sc-5.3.1.tgz

字体无法加载时回退至系统中文无衬线字体。
